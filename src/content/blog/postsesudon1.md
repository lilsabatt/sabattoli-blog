### resumen sobre como arme sabattoli.bar
Primero compré el dominio sabattoli.bar en NameCheap.com por menos de 3 dólares. Después instalé Node.js y Git en mi computadora, dos programas que no sabía ni que existían hace dos horas. Con eso listo, usé Astro, un framework para armar paginas web, que generó toda la estructura base del blog (creo). Para escribir el código usé Visual Studio Code, el estandar de la industria que Peter Wharton sabra explicar porque. Los comentarios que ven al final de cada post los maneja Giscus, que usa GitHub por atrás (los invito a hacerse una cuenta de Github para poder comentar y alimentar el debate sano). Y todo esto está hosteado en Vercel, que agarra mi código de GitHub y lo publica en internet automáticamente cada vez que hago un cambio. Espero les guste la onda 2000esca que tiene la web.
